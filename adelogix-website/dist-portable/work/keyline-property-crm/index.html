Case study

How Keyline came together.

Demo case study: fictional content showing the structure every real project story will follow.

Project overview

Keyline is a CRM shaped around a property agency’s pipeline, from enquiry to viewing, offer and completion.

Business context

A property agency with a sales and a lettings team, using a generic CRM that did not reflect how deals progress in property.

The challenge

Enquiries arrived from several portals and were copied in by hand. Viewings lived in personal calendars, and managers could not see which properties were stalling.

The solution

We built a pipeline with property-specific stages, automatic lead import from web forms and portals, shared viewing calendars and a dashboard showing time-in-stage for every listing.

Key features and development

  • Automatic lead capture from web forms and portals
  • Pipeline stages for sales and lettings
  • Viewing scheduling with shared calendars
  • Property and applicant matching
  • Follow-up reminders for agents
  • Listing performance dashboard

Technology used

  • Laravel
  • PHP
  • MySQL
  • React
  • Figma

What the project set out to achieve

  • Stop re-typing enquiries from listing portals
  • Show managers where each listing is stalling
  • Make sure every applicant gets a follow-up

Measured results will be added only when they can be supported by evidence.

Client feedback

The pipeline finally matches how our agents work. Nobody keeps their own spreadsheet any more.
